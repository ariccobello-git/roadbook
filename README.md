# Roadbook
App (PWA) del Roma Chapter per organizzare i Run. Pubblicata con GitHub Pages dalla cartella radice del ramo `main`.

- Test: `cd tests && npm i && node keys.test.js && node logic.test.js` (le prove a schermo partono con `npm test` dopo `npm run serve`).
- CI: `.github/workflows/test.yml` prova l'app su Ubuntu, macOS e Windows con Chromium, Firefox e WebKit (Safari), emulando Android, iPhone, iPad, Mac e PC.
